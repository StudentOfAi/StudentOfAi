## The Stack I Ship

Every project below is one stage of the same end-to-end system:

```
Find demand  →  Create content  →  Render media  →  Ship product  →  Prove rigor
```

### 1 · Find demand
**[reddit-lead-gen-analytics](https://github.com/StudentOfAi/reddit-lead-gen-analytics)** — Mines subreddits for recurring pain points and clusters them into a market-intelligence report. Stdlib-only Python, CI, full test suite.

### 2 · Create content
**[content-mate](https://github.com/StudentOfAi/content-mate)** — End-to-end content pipeline: scrape → create → publish from one CLI, driven by an Airtable control panel. Runs unattended.

### 3 · Render media
**[viralcut](https://github.com/StudentOfAi/viralcut)** — AI viral-clipping engine: scores footage for hooks, pattern interrupts, and story arcs, then renders vertical clips with animated captions. Strict TypeScript + Remotion, 50+ tests.

**[fastapi-ffmpeg-stitch](https://github.com/StudentOfAi/fastapi-ffmpeg-stitch)** — The rendering microservice behind the pipeline: REST API that stitches images + audio into .mp4 via FFmpeg. Tested, CI-backed.

### 4 · Ship product
**[Home-Director](https://github.com/StudentOfAi/Home-Director)** — A shipped desktop app: local RAG chatbot over your entire home directory. Electron + Flask + Ollama with a zero-dependency binary vector store. No cloud, no API keys.

### 5 · Prove rigor
**[riddle-loop](https://github.com/StudentOfAi/riddle-loop)** — A riddle that finds you while you work. Zero dependencies, cross-platform, 3-OS CI matrix, a test suite where every test encodes a bug that actually happened. The repo to spot-check if you're wondering whether I test my claims.

### Side quest
**[ai-game-solvers](https://github.com/StudentOfAi/ai-game-solvers)** — Autonomous 0-player game solvers, live in-browser: Minesweeper CSP inference, Pac-Man A* with ghost avoidance, Snake BFS + flood-fill autopilot, Word Search 8-directional scanner. [▶ Play live](https://studentofai.github.io/ai-game-solvers/)

## How I Work

1. **Tear it apart** — I don't just use tools. I break them, audit their outputs, and find where they fail.
2. **Build the pipeline** — If a process is manual and repetitive, I script it. Python + CLI tools + automation.
3. **Evaluate relentlessly** — Every AI output gets audited for logical failures, prompt drift, and edge cases before it touches production.
4. **Document everything** — If it isn't written down, it doesn't exist.
